# Система тем NovaCMS

Реализовано в RELEASE 2.3 (PHASE A + B). Документ описывает то, что действительно работает,
и честно называет границы.

---

## 1. Как устроена тема

Тема — каталог в `themes/` с манифестом и каркасом:

```
themes/
  school/
    theme.json      ← манифест: идентификатор, название, версия, автор, макеты
    layout.php      ← каркас: <html>, шапка, main, подвал
    page.php        ← (необязательно) перекрывает встроенный шаблон страницы
    partials/       ← (необязательно) перекрывает партиалы
    sections/       ← (необязательно) перекрывает виды секций
```

Тема перекрывает **только те файлы, которые положила**. Нет `page.php` — берётся встроенный.
Это та же иерархия, что уже была в `resolveTemplate()`, просто к ней добавился каталог темы.

## 2. Манифест `theme.json`

```json
{
  "slug": "school",
  "name": "Школа",
  "version": "1.0.0",
  "description": "Тема школы английского",
  "author": "NovaCMS",
  "license": "MIT",
  "preview": "screenshot.png",
  "colors": {"accent": "#b45309"},
  "layouts": ["default", "landing", "full-width"]
}
```

### Обязательные поля

| Поле | Правило |
|---|---|
| `slug` | уникален, только `a-z`, `0-9`, дефис; совпадает с именем каталога |
| `name` | отображаемое название, непустое |
| `version` | строка версии (`1.0.0`) |

### Необязательные

`description`, `author`, `license`, `preview`, `colors`, `layouts`.

### Валидация

`themeManifestParse()` возвращает разобранный манифест либо текст отказа. Правила:

- битый JSON → отказ, а не «пустой манифест»;
- небезопасный `slug` (пробелы, `/`, `..`, заглавные) → отказ;
- отсутствие обязательного поля → отказ с именем поля;
- тема без `layout.php` → помечается «повреждённая» с причиной.

Отказ не роняет каталог: остальные темы остаются доступны.

## 3. Реестр и активация

- `themeRegistryRead()` читает `themes/` и делит содержимое на «годные» и «повреждённые».
- Активная тема хранится в настройке `active_theme` (`tbl_option`).
- Пустое значение = встроенная тема `theme/`.
- `themeActivate()` проверяет, что каталог и `layout.php` на месте, иначе отказ.
- `themeDeactivate()` возвращает встроенную тему.

### Что происходит при активации

1. Проверка манифеста и наличия каркаса.
2. Запись `active_theme` в настройки.
3. Запись события в журнал (`auditLog`).
4. Страница начинает рендериться каркасом темы.

### Откат

Кнопка «Сделать активной» у карточки встроенной темы снимает `active_theme`. Автоматического
отката при ошибке рендеринга **нет** — это не реализовано (см. §6).

---

## 4. Экран «Дизайн → Темы» (`/admin/themes`)

- карточки тем: название, версия, автор, описание, статус;
- статусы: «Активная», «Доступна»;
- кнопки «Активировать» / «Сделать активной»;
- право `manage` — переключение темы меняет весь сайт;
- плашки `theme_activated` / `theme_deactivated`.

Список тем формируется из каталога: положили каталог в `themes/` — он появился в админке.

---

## 5. Совместимость

- Пока `active_theme` пуста, поведение сайта прежнее (встроенный каркас).
- Существующие страницы, SEO, адреса и содержимое не меняются.
- Миграций схемы нет: настройка живёт в `tbl_option`, как все прочие.
- Тема не может перекрыть ядро: `resolveTemplate()` смотрит каталог темы, но не позволяет
  выйти за его пределы.

---

## 6. Ограничения (честно)

| Что | Статус |
|---|---|
| Установка темы из ZIP | **не реализовано** — нет защиты от Zip Slip, проверки путей и типов |
| Автоматический откат при ошибке рендеринга | **не реализовано** |
| Скриншоты тем | поле в манифесте есть, показ не сделан |
| Настройки темы (цвета, шрифты) | **не реализовано** — Design System не начат |
| Экспорт/импорт темы | **не реализовано** |
| Несколько каркасов внутри одной темы | **не реализовано** |

Установка из ZIP требует отдельного набора тестов безопасности и в этот заход не входила:
каталог `themes/` наполняется файлами на сервере, экран показывает то, что уже лежит.

## 7. Связанные файлы

| Файл | Роль |
|---|---|
| `core/theme.php` | манифест, реестр, активация |
| `core/template.php` | `render()` → `resolveTemplate('layout')` |
| `core/templates/admin/themes.php` | экран каталога |
| `core/routes.php` | маршруты `GET/POST /admin/themes` |
| `core/notice.php` | ключи `theme_activated`, `theme_deactivated` |
| `themes/school/` | первая тема |
| `tests/unit/ThemeRegistryTest.php` | манифест и реестр |
| `tests/http/ThemesAdminTest.php` | экран и активация |
