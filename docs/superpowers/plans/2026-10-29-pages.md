# CMS-страницы из блоков и конструктор — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** сайт рисует произвольные страницы из секций: главная «/» и страницы `/{slug}` собираются
строками таблиц ядра, редактор — в `/admin`, приложения (новости) подставляют живые блоки фильтрами.

**Architecture:** ядро хранит `tbl_page`, `tbl_page_section`, `tbl_page_old_slug` (релиз
`sql/0002_pages.sql`). Публичный рендер — диспетчер `sectionHtml()`: известные виды ядра рисуют
шаблоны `theme/sections/<kind>.php`, чужие виды уходят фильтру `pages_block_<kind>` (вклад
приложения), пустой ответ — секция не печатается. Точные маршруты реестра выигрывают у
`/{slug}` по построению сортировки роутера. Конструктор — экраны `/admin/pages*` на праве
`manage`, действия одним POST-обработчиком с `op` и CSRF. Гонки уникальных ключей (слаг страницы,
ключ секции) отвечают человеку через `duplicateReason()`.

**Tech Stack:** PHP 8.3, MySQL 8 (InnoDB, utf8mb4_unicode_ci), PHPUnit (наборы `unit` / `db` /
`http` / `guard`), Tailwind v4 (только существующие утилиты — без новых CSS-правил), стражи
`tests/guard/`.

**Спецификация:** `docs/superpowers/specs/2026-10-29-pages-design.md` — решения 1–7 штурма, схема
§1, рендер §2, виды §3, конструктор §4, вклады §5. При расхождении действует спецификация,
найденное расхождение записывается вердиктом контроллера в ledger.

## Глобальные ограничения

- Только PHP 8.3 и MySQL: ни одной runtime-зависимости, ни одного нового пакета.
- Все строки, комментарии и имена тестов — по-русски. Идентификаторы — по-английски.
- Разметка печатается через `e()`; сырой HTML — только переменным `$content`/`$head`/`$footer`
  с пометкой `/* @safe html */` (страж `OutputEscapingTest`).
- Каждый контроль админки несёт класс `min-h-[44px]` (страж `TapTargetTest`).
- Новых CSS-правил нет: секции собираются существующими утилитами Tailwind; иначе краснеет
  шаг свежести артефакта и `StyleSourceTest`.
- SQL пишется параметрами; имена таблиц — через `t()`; в релизе схемы — литералы `tbl_…`
  (стражи `AppSqlTest`, `SqlSafetyTest`); релиз идемпотентен (`CREATE TABLE IF NOT EXISTS`).
- Пути POST-обработчиков — строковые литералы в `core/routes.php` (страж `CsrfCoverageTest`
  читает их регуляркой).
- Время — только `nowUtc()`/`utcStamp()` (страж `DateUsageTest`); ключи уведомлений —
  в словаре ядра (страж `NoticeKeyTest`).
- Каждый релиз схемы идемпотентен: MySQL фиксирует DDL до записи в журнал.
- Коммит обычной формой (автор уже в config — `Алексей <zanzibaradevil@gmail.com>`, config
  git не трогать). Пуш — только по явной команде человека, никогда с `-u`.
- Ворота (`bash scripts/gate.sh` через Git Bash) не ослабляются: падает PHPStan или фиксер —
  чинится код, правки `ignore` и подавления запрещены.
- Тест сверяется с базой, а не с кодом самого теста; проверка, которая не способна покраснеть,
  чинится мутацией, а не новым утверждением.
