# Перенос данных из PostgreSQL и переключение домена — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** перенести содержимое живого портала (`english_portal`, PostgreSQL) в CMS на MySQL — аккаунты
с прежними паролями, программу курсов с упражнениями, меню, страницы конструктора и заявки — а затем
переключить домен так, чтобы школа не потеряла ни материала, ни аккаунта, ни адреса.

**Architecture:** правила переноса живут в `core/import.php` под стражами (чистые функции: роли,
моменты, JSON, строки секций, пути картинок); `scripts/import-portal.php` — тонкая оболочка чтения
`dump/*.jsonl` и печати отчёта; выгрузка дампа — `scripts/portal-export.sh` во временную базу
`postgres:17`. По умолчанию скрипт работает в режиме проверки и в базу не пишет.

**Tech Stack:** PHP 8.3, MySQL 8 (InnoDB, utf8mb4_unicode_ci), PostgreSQL 17 только для выгрузки
дампа (Docker, на машине разработчика), PHPUnit (наборы `unit` / `db` / `guard` / `http`).

**Спецификация:** `docs/superpowers/specs/2026-11-11-postgres-import-design.md` — способ чтения §2,
идентификаторы §3, карта переноса §4, скрипт §5, переключение домена §6, тесты §7, вердикты §9.

## Глобальные ограничения

- Только PHP 8.3 и MySQL: ни одной runtime-зависимости в продукте. `scripts/` — инструмент
  разработчика, на хостинг не едет (`deploy.sh` его исключает).
- Идентификаторы `cuid` переносятся как есть: на них держатся JSON-связи (`lessonId`, `questionId`).
- Пароли — прежние bcrypt-хеши `$2b$`; PHP проверяет их нативно, `needsRehash()` поднимет алгоритм
  при первом входе.
- Все строки, комментарии и имена тестов — по-русски. Идентификаторы — по-английски.
- Время — только `nowUtc()`/`utcStamp()`; разбор моментов — `core/import.php`, а не `date()`.
- SQL — параметрами через `insert()`/`run()`; имена таблиц — через `t()`.
- Режим проверки по умолчанию: запись в базу только с явным `--write`.
- Новых CSS-утилит перенос не приносит: артефакт стилей обязан совпасть побайтово.
- Коммит после зелёного полного гейта; пуш — только по явной команде человека.

## Задача 1: правила переноса в `core/import.php`

**Файлы:** создать `core/import.php`, `tests/unit/ImportTest.php`.

- [x] Роли: `importRole('ADMIN') === 'admin'`, `CONTENT_MANAGER` → `editor`, `STUDENT` → `student`,
      неизвестная роль → исключение с человеческим текстом.
- [x] Момент: `importStamp('2026-10-01T05:35:04.744')` → `'2026-10-01 05:35:04'` в UTC;
      пустое → `null`; мусор → `null`.
- [x] День: `importDay('2026-10-04T05:34:30.775')` → `'2026-10-04'`; пустое → `null`.
- [x] JSON: `importJsonList(null) === '[]'`, `importJsonList([{...}])` — валидный JSON с
      `JSON_UNESCAPED_UNICODE`; `importJsonObject(null) === '{}'`.
- [x] Имя: `importUserName('', 'a@b.ru') === 'a'`, непустое имя обрезается до 120.
- [x] Путь картинки: `/longread/x.png` → `/assets/longread/x.png`; чужой домен и пустое — как есть.
- [x] Строка секции: `pageId` NULL → `page_id = ''`; `key` → `sec_key`; `lead` → `lead_text`;
      `gallery` дописывается в `items` с `title` из `text`; `settings` → `'{}'`.
- [x] `importStat()` печатает «прочитано / перенесено / пропущено / причина».
- [x] Проверка: `tests/unit/ImportTest.php` зелёный.

## Задача 2: перенос в базу с идемпотентностью

**Файлы:** правка `core/import.php`, создать `tests/db/ImportTest.php`.

- [x] `importUpsert()`: строка с существующим `id` не перезаписывается; совпадение — «уже есть»,
      расхождение — «в базе другое значение» и запись в «Требуют внимания».
- [x] `importOrphans()`: строка без родителя не пишется и попадает в отчёт.
- [x] Порядок таблиц: аккаунты → дерево курса → упражнения и попытки → меню, страницы, заявки.
- [x] `$2b$`-хеш портала переносится без пересчёта: `password_verify('пароль', $hash)` истинно,
      `needsRehash()` — истинно (алгоритм поднимется при входе).
- [x] Проверка: `tests/db/ImportTest.php` зелёный, включая «повторный прогон не дублирует».

## Задача 3: скрипт `scripts/import-portal.php`

**Файлы:** создать `scripts/import-portal.php`, `scripts/portal-export.sh`.

- [x] Аргументы: `--dump=<каталог>` обязателен, `--write` включает запись, `--assets=<каталог>`
      копирует картинки портала.
- [x] Без `--write` в базу не пишет ничего: счётчик строк до и после совпадает.
- [x] Отчёт: по таблице «прочитано / перенесено / пропущено», затем «Требуют внимания человека»
      (сироты, расхождения, отсутствующие картинки, секции `levels`).
- [x] Код выхода 1 на любую ошибку чтения или неизвестное значение.
- [x] Проверка: режим проверки на развёрнутом дампе печатает ожидаемые числа.
