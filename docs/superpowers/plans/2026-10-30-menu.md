# Меню шапки и подвала из базы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** навигация сайта (шапка, колонки подвала) живёт в базе: пункты правятся в `/admin/menu`,
выключенный раздел прячет свою ссылку сам, день-1 пустое меню сайт не ломает.

**Architecture:** плоский `tbl_menu_item` (слот, подпись колонки подвала, подпись, адрес, «в новом
окне», порядок, видимость) по образцу `MenuItem` портала; чтение — `menuHeaderLinks()` /
`menuFooterSections()` из `core/menu.php`, тема рисует их существующими утилитами; ссылки разделов
ядро собирает из `publicNav` манифестов ВКЛЮЧЁННЫХ приложений и дописывает в шапку. Экран
`/admin/menu` — один POST-обработчик с `op`, перестановка — обмен с соседом и пересборка порядка.

**Tech Stack:** PHP 8.3, MySQL 8 (InnoDB, utf8mb4_unicode_ci), PHPUnit (наборы `unit` / `db` /
`http` / `guard`), Tailwind v4 (только существующие утилиты — без новых CSS-правил), стражи
`tests/guard/`.

**Спецификация:** `docs/superpowers/specs/2026-10-30-menu-design.md` — решения 1–10 штурма,
схема §1, чтение §2, админка §3, тесты §4. При расхождении действует спецификация, найденное
расхождение записывается вердиктом контроллера в ledger.

## Глобальные ограничения

- Только PHP 8.3 и MySQL: ни одной runtime-зависимости, ни одного нового пакета.
- Все строки, комментарии и имена тестов — по-русски. Идентификаторы — по-английски.
- Разметка печатается через `e()`; сырой HTML — только переменным `$content`/`$head`/`$footer`
  с пометкой `/* @safe html */` (страж `OutputEscapingTest`).
- Каждый контроль админки несёт класс `min-h-[44px]` литералом (страж `TapTargetTest`).
- Новых CSS-правил нет: меню собирается существующими утилитами Tailwind.
- SQL пишется параметрами; имена таблиц — через `t()`; в релизе схемы — литералы `tbl_…`
  (стражи `AppSqlTest`, `SqlSafetyTest`); релиз идемпотентен (`CREATE TABLE IF NOT EXISTS`).
- Пути POST-обработчиков — строковые литералы в `core/routes.php` (страж `CsrfCoverageTest`);
  `csrfCheck()` — первый вызов обработчика.
- Время — только `nowUtc()`/`utcStamp()`; ключи уведомлений — в словаре ядра
  (страж `NoticeKeyTest`); чтение меню — с LIMIT (страж `PerformanceTest`).
- Коммит после зелёного полного гейта; пуш — только по явной команде человека.

Создаются:

| Файл | Ответственность |
| --- | --- |
| `sql/0003_menu.sql` | релиз: `tbl_menu_item` |
| `core/menu.php` | константы, валидатор href, читатели, сбор publicNav, операции записи |
| `core/templates/admin/menu.php` | экран «Меню»: карты «Шапка» и «Подвал» |
| `tests/unit/MenuRulesTest.php` | чистые правила: валидатор, нормализация, колонки, publicNav |
| `tests/db/MenuTest.php` | операции на живой базе: порядок, видимось, удаление, пустой слот |
| `tests/http/MenuAdminTest.php` | права, CSRF, PRG-ключи, отказы формы |
| `tests/http/MenuPublicTest.php` | шапка/подвал из базы, blank, скрытые, выключенный раздел |

Правятся:

| Файл | Что меняется |
| --- | --- |
| `apps/{news,commerce,classifieds}/manifest.php` | поле `publicNav` |
| `theme/partials/header.php` | пункты из базы + разделы вместо статической «Новости» |
| `theme/partials/footer.php` | колонки из базы вместо статической «Новости» |

| `core/bootstrap.php` | подключение `core/menu.php` |
