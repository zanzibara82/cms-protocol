Руководство по установке CMS «Школа английского» на виртуальный хостинг

Версия: 1.0  |  Для: новичков и владельцев виртуального хостинга

Что вам понадобится:

  • Доступ к панели управления хостингом (cPanel, ISPmanager, DirectAdmin или другая)
  • Доступ к файловому менеджеру хостинга или FTP-клиент (FileZilla, WinSCP)
  • База данных MySQL (имя базы, пользователь, пароль, хост)
  • Название сайта, адрес электронной почты администратора и пароль

Важно: Ниже в документе есть блоки для скриншотов. Если вы делаете этот документ для себя, просто пропустите их или вставьте свои скриншоты. Если делаете для другого человека — замените каждый блок на реальный скриншот из вашего хостинга.

Чеклист перед началом

  • У меня есть доступ к панели управления хостингом
  • У меня есть FTP-доступ или файловый менеджер
  • Я знаю имя базы данных, пользователя и пароль MySQL
  • У меня есть название сайта, email администратора и пароль (минимум 10 символов)

Шаг 1. Подготовка файлов на компьютере

Скачайте архив с CMS и распакуйте его в отдельную папку на компьютере, например в папку cms-ready.

В этой папке должны быть:

  • public/ — основные файлы сайта (включая index.php, setup.php, .htaccess, assets/app.css)
  • core/ — ядро системы
  • admin/ — каркас админки
  • theme/ — шаблоны оформления
  • apps/ — приложения (Новости, Курсы, Магазин и т.д.)
  • config.sample.php — образец файла настроек
  • composer.json и composer.lock
  • scripts/ — служебные скрипты

Скриншот 1: Покажите окно проводника Windows с открытой папкой cms-ready/, где видны папки public/, core/, admin/, theme/, apps/ и файлы config.sample.php, composer.json.

Не загружайте на хостинг:

  • Папку vendor/ (если есть возможность установить Composer на хостинге — делайте это там)
  • Папку .superpowers/ (внутренний журнал разработки)
  • Папку tests/ (тесты не нужны на рабочем сайте)
  • Файл public/install.lock (создастся автоматически при установке)

Шаг 2. Загрузка файлов на хостинг

Загрузите файлы двумя способами: через файловый менеджер панели управления или через FTP.

Вариант А: Через файловый менеджер панели управления

  1. Войдите в панель управления хостингом.
  2. Найдите «Файловый менеджер» или «File Manager».
  3. Перейдите в корневую папку вашего сайта (обычно public_html, www или httpdocs).
  4. Загрузите содержимое локальной папки public/ в папку public_html/public/.
  5. Загрузите папки core/, admin/, theme/, apps/ в корневую папку сайта.
  6. Загрузите файл config.sample.php в корневую папку сайта.

Скриншот 2: Файловый менеджер хостинга. Видны папки public/, core/, admin/, theme/, apps/ и файлы config.sample.php, composer.json.

Вариант Б: Через FTP-клиент (FileZilla)

  1. Подключитесь к хостингу через FTP.
  2. Перейдите в корневую папку сайта.
  3. Перетащите папки и файлы из локальной папки cms-ready/ на сервер.

Шаг 3. Настройка прав доступа к файлам

Права доступа определяют, кто может читать и записывать файлы. Выставьте следующие права:

Папка / файлПраваЗачем
public/755Папка сайта доступна для чтения и записи
public/assets/755CSS и картинки доступны для чтения
public/uploads/777 или 755Загрузка файлов пользователями (аватары, картинки)
config.php600Только владелец может читать и писать (создастся при установке)
public/install.lock644Замок установщика (создастся после установки)

Как выставить права в файловый менеджер хостинга:

    1. Нажмите правой кнопкой мыши на папку или файл. 2. Выберите «Права доступа» или «Change permissions». 3. Введите цифровой код (например, 755 или 600). 4. Нажмите «ОК» или «Применить».

Скриншот 3: Окно изменения прав доступа в файловый менеджер хостинга. Видно поле с цифровым кодом (например, 755 или 600).

Шаг 4. Создание базы данных на хостинге

  1. В панели управления хостингом найдите раздел «Базы данных MySQL» или «MySQL Databases».
  2. Нажмите «Создать базу данных». Придумайте имя, например cms_prod или u12345_cms.
  3. Создайте нового пользователя базы данных, например cms_user.
  4. Придумайте надёжный пароль (минимум 10 символов, буквы, цифры, спецсимволы).
  5. Привяжите пользователя к базе данных с правами «Все привилегии» (All privileges).
  6. Запишите на бумаге: имя базы, имя пользователя, пароль, хост (обычно localhost).

Скриншот 4: Страница создания базы данных в панели управления хостингом. Видны поля для имени базы, пользователя и пароля.

Шаг 5. Создание файла настроек config.php

  1. Скачайте файл config.sample.php с хостинга на ваш компьютер.
  2. Откройте его в текстовом редакторе (Notepad++, VS Code, Блокнот).
  3. Заполните следующие строки:
return [
    'DB_HOST' => 'localhost',           // обычно localhost
    'DB_PORT' => '3306',                // обычно 3306
    'DB_NAME' => 'cms_prod',            // имя вашей базы данных
    'DB_USER' => 'cms_user',            // имя пользователя БД
    'DB_PASS' => 'ваш_надёжный_пароль', // пароль пользователя БД
    'TABLE_PREFIX' => 'tbl_',
    'SITE_URL' => 'https://ваш-сайт.ru', // адрес сайта с https://
    'SITE_NAME' => 'Моя школа английского',
    'TIMEZONE' => 'Europe/Moscow',
    // SMTP настройки (опционально, для отправки почты):
    // 'SMTP_HOST' => '',
    // 'SMTP_PORT' => '587',
    // 'MAIL_FROM' => 'noreply@ваш-сайт.ru',
];

Скриншот 5: Файл config.php в текстовом редакторе. Видны заполненные поля DB_HOST, DB_NAME, DB_USER, SITE_URL.

  1. Сохраните файл как config.php (без слова sample).
  2. Загрузите config.php в корневую папку сайта (рядом с папкой public/).
  3. Выставьте права на файл config.php: 600 (только владелец может читать и писать).

Никогда не отправляйте config.php по электронной почте и не храните его в открытом доступе. В файле содержится пароль от базы данных.

Шаг 6. Запуск установщика

  1. Откройте любой веб-браузер.
  2. В строке адреса введите: https://ваш-сайт.ru/setup.php
  3. Вы должны увидеть страницу «Установка сайта».

Скриншот 6: Страница установщика CMS с формой ввода данных.

  1. Если вы видите ошибки красным цветом — проверьте:
    • Права на запись в папку public/ (нужны для создания файла install.lock)
    • Версию PHP (должна быть не ниже 8.1)
    • Наличие расширений pdo_mysql, mbstring, openssl, fileinfo
  2. Заполните форму установки:
    • Название сайта: например «Моя школа английского»
    • Почта администратора: ваш рабочий email
    • Имя администратора: ваше имя
    • Пароль: придумайте надёжный пароль (минимум 10 символов)
    • Пароль ещё раз: повторите тот же пароль
  3. Нажмите кнопку «Установить».

Скриншот 7: Заполненная форма установщика с введённым названием сайта, почтой, именем и паролем.

Если всё прошло успешно: вы увидите сообщение об успешной установке и ссылку на вход в кабинет администратора.

Шаг 7. Первый вход в кабинет администратора

  1. Нажмите ссылку на вход или перейдите по адресу: https://ваш-сайт.ru/login
  2. Введите email администратора и пароль, которые указали при установке.
  3. Нажмите «Войти».
  4. Вы должны попасть в кабинет администратора с вкладками «Сводка», «Приложения» и т.д.

Скриншот 8: Страница входа в кабинет администратора CMS.

Шаг 8. Установка разделов (приложений)

После входа в кабинет:

  1. Нажмите вкладку «Приложения» (или «Админка приложений»).
  2. Вы увидите список доступных разделов:
    • Новости — публикация статей
    • Курсы — обучающие курсы для учеников
    • Магазин — интернет-магазин
    • Доска объявлений — доска частных объявлений
    • SEO и статистика — аналитика посещаемости
  3. Для каждого раздела, который хотите использовать, нажмите кнопку «Установить».
  4. После установки раздел появится в меню сайта и в кабинете.

Скриншот 9: Страница управления приложениями /admin/apps со списком разделов и кнопками «Установить».

После установки настройте каждый раздел:

РазделЧто настроить
НовостиСоздайте рубрики (например, «Новости школы», «Объявления») и первые материалы
КурсыСоздайте уровни (Pre-A1, A1, A2, B1, B2, C1, C2), курсы, модули и уроки
МагазинСоздайте товары, настройте способы оплаты

Шаг 10. Настройка электронной почты (опционально)

Если хотите получать уведомления и отправлять письма пользователям (восстановление пароля, уведомления о заказе):

  1. В панели управления хостинга создайте почтовый ящик (например, noreply@ваш-сайт.ru).
  2. В файле config.php добавьте или отредактируйте:
'SMTP_HOST' => 'ssl://smtp.your-hosting.ru',
'SMTP_PORT' => '465',
'MAIL_FROM' => 'noreply@ваш-сайт.ru',
'MAIL_FROM_NAME' => 'Моя школа',
  1. Проверьте отправку тестового письма через кабинет администратора.

Итоговый чеклист перед запуском

  • Все файлы загружены на хостинг
  • Права на public/uploads/ — 777 или 755
  • Права на config.php — 600
  • База данных создана и пользователь привязан
  • Файл config.php заполнен и загружен
  • Установщик пройден (/setup.php), создан аккаунт администратора
  • Файл public/install.lock существует (установщик заблокирован)
  • Разделы установлены через /admin/apps
  • Сайт открывается по главному адресу
  • Админка открывается по адресу /admin
